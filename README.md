## 会员、API 与积分兑换规则

积分（Token）是所有服务共用的结算单位，底层对应真人的时间价值。用户通过积分兑换约定的服务交付；除超级会员外，不开放按零碎时间兑换真人支持。

| 项目 | 规则 |
| --- | --- |
| 积分基准 | 1 积分 = 1 分钟标准时间价值，最小计价和使用单位为 1 积分。 |
| 零售 / API | API 采用零售积分模式，最小可售单位为 60 积分，购买后一次性到账；调用服务按对应 Skill 的标价扣分。60 积分是购买门槛，不是每次消费的最低额度。 |
| 会员套餐 | 会员采用打包购买方式，套餐积分一次性到账，不按月发放或释放兑换额度。 |
| 积分累计 | 未使用积分可以保留、累计；具体有效期和跨年规则另行明确。 |
| 预约限制 | 积分到账不代表可以立即占用对应时间。兑换服务需要预约，交付时间按服务约定和可用排期确定。 |
| 普通兑换 | 普通用户及普通会员只能兑换已提供的 Skill 服务，按具体服务标价扣分，不能直接兑换零碎时间。 |
| 超级会员 | 除兑换 Skill 服务外，还可以预约按时间计价的真人直接支持，按约定时长及积分基准计价。 |

### 服务定价与交付

每个 Skill 应明确积分售价、交付内容、所需材料、服务范围、包含的修改次数，以及预约和交付时效。不同服务可以采用不同的积分售价。

服务标价与实际耗时分开：例如，一项服务标价为 120 积分，兑换的是约定的交付内容，不代表购买必须持续 120 分钟的过程。服务范围内不因实际完成得更快或更慢而多退少补；超出范围的需求需另行确认报价。超级会员预约的按时服务按约定时长计价。

预约流程为：选择服务 → 确认范围与排期 → 冻结积分 → 完成交付后扣除。取消、改期以及超出服务范围的处理规则，应在预约时明确。

积分余额代表可购买的服务价值，实际交付容量由预约排期管理，不采用按月释放积分或兑换额度的方式。以上为服务规则约定，当前预览页面尚未实现积分账户、冻结扣费、API 调用或自动预约系统。

## 用户隐私与双方保密规则

双方对接、咨询、沟通、协作和交付的过程及内容默认保密，无需额外标注“保密”。这一原则从首次咨询开始适用，不以成交、付费或会员等级为条件，合作结束后继续有效。除下述必要披露情形外，只有在双方明确同意后，才可在约定范围内公开。

### 保密与公开范围

- **双方保密**：保护合作关系、未公开的身份与联系方式、需求与咨询问题、文件和数据、个别报价与预约信息、聊天及会议记录、过程稿、源文件和最终交付内容。不得擅自披露对方信息，也不得将其用于本次服务以外的用途。
- **交付成果的正常使用**：在服务确认时明确使用权、是否允许公开发布、发布范围及时间。例如，双方可以事先同意用户将交付的音乐用于游戏发行，或上线交付的网站；用户在已确认范围内使用或发布，无需逐次重新申请。未约定公开的内容仍默认保密，发布成品不自动开放聊天记录、过程稿或源文件。
- **案例与宣传另行授权**：将合作用于作品集、案例、客户名单、评价引用或截图分享，须另外取得双方明确同意；即使匿名或打码，也不能默认公开。用户发布成品，不等于授权服务方展示案例或披露合作关系。拒绝宣传授权不影响已约定的服务、价格和交付。
- **授权要具体且可留存**：以聊天文字、邮件或订单确认等方式记录公开的内容或版本、用途、渠道、署名方式以及期限或发布时点。超出范围需重新确认；沉默、付款和验收不构成公开授权。双方的同意不能代替涉及的第三方所需授权。

### 信息处理与 AI 使用

- **最少必要信息**：仅收集完成咨询、预约、结算和交付所需的信息，限制材料访问范围，不擅自转给其他客户或协作者。提交材料前尽量去除无关个人信息；需要账号访问时，优先使用临时、最小权限授权。
- **工具授权与公开授权分开**：使用 AI 辅助不等于同意上传所有材料，允许工具处理也不等于允许公开。首次使用外部 AI、云服务或第三方协作者处理保密材料前，应说明接收方、用途、材料范围、留存与训练设置，以及是否涉及境外处理，并取得相应授权。可以在咨询开始或订单中对明确的工具和用途一次确认，无需在范围不变时逐次确认；更换接收方、扩大数据范围或改变用途时重新确认。
- **授权必须可执行**：只将必要材料交给符合约定处理条件的工具或协作者，并落实相应访问限制和保密安排。处理条件不清楚或无法满足时，不上传相关材料，先协商脱敏、本地处理或调整服务方案。涉及第三方个人信息或保密材料时，应核实有权提供和处理，不能仅凭上传者同意即视为已获得全部授权。
- **不默认复用材料**：不将保密材料用于模型训练、共享知识库、公开数据集或其他客户的交付。确需复用时，须另行明确材料范围和用途并取得相应授权，不与完成本次服务的授权混为一体。

### 留存、删除与必要披露

- **留存有期限**：收集前说明资料类型、用途、保存期限或明确的到期条件，以及查询、更正、删除和撤回授权的联系渠道。咨询材料、交付文件、账务记录及备份分别管理，不以“售后需要”为由无限期保存全部材料。到期或目的已实现且无需继续保存时，按适用要求删除或返还。
- **删除与撤回**：收到请求后确认范围、处理安排并反馈结果。对依法需保留或技术上暂不能删除的记录，说明原因、范围和后续处理安排，限制后续使用及访问。撤回案例或宣传授权后，停止新增使用，并及时处理可控制渠道中的相关内容；不承诺清除第三方已转载或缓存的副本。宣传授权的撤回不自动撤销用户已取得的交付成果使用权。
- **必要披露**：依法向有权机关提供信息，或为投诉、争议处理向有权受理机构及承担保密义务的专业顾问提供必要证据，不以对方同意为前提；披露限于必要范围，并在法律允许且不妨碍相关程序时告知对方。保密规则不用于阻止依法维权。
- **异常处理**：发现材料误发、泄露或未经授权的访问时，及时采取补救措施，按适用要求告知受影响方，说明已知范围、影响和处理进展。

不依赖对方保密信息而独立形成的通用方法、合作前已有的材料，以及非因违反保密义务而已合法公开的信息，不因本次合作自动成为对方的保密材料；但这一边界不授权复用客户专属内容、披露未公开的合作细节或对外宣传合作关系。交付成果的版权归属和使用许可另行明确。

以上为服务规则，具体工具清单、保存期限和联系渠道仍需在实际收集资料前补齐并展示给用户，不能仅凭本节视为已完成全部告知或授权。涉及个人信息时，还应满足适用的告知、授权、委托处理及跨境处理要求；可参考《[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)》第十七条、第二十一条、第二十三条、第三十八至三十九条及第四十七条。
