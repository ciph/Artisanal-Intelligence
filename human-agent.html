总量、预售额度与个人余额是什么关系？

每个服务年度计划提供 1,000 小时，即 60,000 Token。本次从中预售 100 小时，即 6,000 Token，占年度总量的 10%。各档会员与 API 共享本次预售额度；个人余额按认领及使用记录核对。服务年度的起止日期、个人额度有效期与跨年处理尚待确认，年度总量不表示个人余额会在年底自动清零。

Token 怎样扣除与记录？

1 Token 对应 1 分钟标准时间价值，最小计价单位为 1 Token；零售 60 Token 起购。普通兑换按 Skill 服务标价扣分，不因实际耗时多退少补。超级会员预约的按时支持按约定时长计价。超出服务范围时先确认报价，扣除、退回与调整均留下记录。

预约、改期和未用额度怎么办？

积分一次到账，未用积分可累计，不按月释放；持有积分后仍需确认可预约时段。改期、取消、退款、有效期及跨年处理会在认领前明确。页面中的方案选择只用于咨询，不会锁定额度或预约。

AI 工具和其他费用包含在内吗？

这里的 Token 用于兑换真人主导的服务。第三方账号、官方订阅和模型调用额度不随之提供。具体工具、素材、部署等费用是否包含，会随协作范围一并说明；另有费用时，先确认再产生。

会交付什么，资料如何使用？

共同确认文件、记录或原型等具体产出，以及交付格式、修改范围、后续支持和成果归属。需要把资料交给第三方 AI 工具处理时，先说明工具、资料范围与使用方式，再确认是否采用。

为什么叫
「真人 Agent」

我把这种协作方式叫作「真人 Agent」：由我理解需求、作出判断并参与执行，AI 是工作中按需使用的工具。

你不必先学会所有工具，也不必带来一份完整的需求。可以从一段作品、一个报错，或一个还没想清楚的想法开始。我们先确认是否适合合作，再约定目标、时间和本次产出。

我希望提供的，是有人听懂问题，也有人一起动手的协作。把范围讲清楚，让过程可沟通，让完成的内容看得见。
